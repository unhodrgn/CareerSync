## 1. Demo scope

### 1.1 Required for the demo (decided)

| Item | Decision |
|---|---|
| Viewing jobs without logging in | `GET /api/jobs`, `GET /api/jobs/{job_id}` public — D4 |
| Match score for seekers | Seekers see the match score (Final, rounded down) with the band (매우 적합/적합/참고: very good/good/reference), plus scores per criterion category and the preference score; each criterion's score on the job detail page; never weights, never on applied jobs — D42, D43 (replace D1, D31) |
| Job recommendation for seekers | Final = 0.5·Fit + 0.5·Pref, threshold 40/40, Pref computed first — D2 |
| AI mode | Rule-based by default; the LLM is turned on with `AI_MODE` — D5, D12 |
| Business registration | 사업자등록번호 (business registration number) is not collected — D32 (replaces D6) |
| Company's running projects | In scope — D8 |
| How the demo runs | Locally with Docker Compose — D7 |
| Talent recommendation (opt-in, anonymous, offer) | Required for the demo — D29 |

### 1.2 In product scope, not yet decided whether required for the demo

In the brief of 2026-10-13. Q10 is closed: AI CV self-check (D25), skill roadmap and interview questions (D21), AI help writing the JD (D24), quick applicant filters (D22) were decided and are done. Items outside the brief are still undecided (Q11).

- Seeker: upload CV / profile, AI self-check of the profile, view jobs + match band, apply, track status, skill roadmap for what is missing, interview questions based on the JD.
- Employer: business registration, post jobs (AI helps write the JD), receive applications, set own evaluation criteria, dashboard of ranked applicants + strengths/weaknesses, quick filters, running projects.
